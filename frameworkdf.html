Discovery & Audyt
Analiza stanu obecnego, zbieranie materiałów, mapowanie problemów
▼
Zanim napiszesz linijkę kodu - zrozum co masz, co nie działa i co realnie wpływa na biznes klienta. Audyt to nie checklist SEO, to mapa operacyjna: co zabija konwersje, co spowalnia stronę, co jest redundantne.

🎯 Działania

  • Audyt obecnej strony (UX, CX, copy, SEO)
  • Inwentaryzacja contentu - keep / kill / merge
  • Mapowanie redirectów (stary → nowy URL)
  • Zebranie brandingu: logo, kolory, fonty, zdjęcia
  • Analiza konkurencji + benchmark

📦 Deliverables

  • Raport audytu z priorytetami (P0/P1/P2/P3)
  • Mapa redirectów 301
  • Content inventory spreadsheet
  • Brand asset kit
  • Competitive brief

02
🏗️
Architektura & Struktura
IA, nawigacja, mapa stron, routing, schema
▼
Architektura informacji to fundament. Bez solidnej IA nawet najładniejszy design nie konwertuje. Definiujesz hierarchię stron, nawigację, URL-e i redirecty zanim dotkniesz CSS-a.

🎯 Działania

  • Mapa stron - główne + deep offer + city pages
  • Nawigacja desktop + mobile
  • URL structure + canonical tags
  • Schema JSON-LD (Organization, BreadcrumbList, Service)
  • Sitemap.xml + robots.txt
  • Mapa 301 redirectów (vercel.json)

📦 Deliverables

  • Sitemap diagram (visual)
  • Routing table (URL → plik)
  • vercel.json z redirectami
  • Schema templates per page type
  • sitemap.xml + robots.txt

🔧 Narzędzia

Mermaid JSON-LD Vercel CLI Google Search Console Schema Validator
03
🎨
Design & Build
HTML/CSS, komponenty, responsive, animacje
▼
Budowa strona-po-stronie z mobile-first approach. Każda strona to system komponentów (hero, cards, CTA, FAQ, footer) - nie jednorazowy layout. Shared CSS zamiast copy-paste per plik. Wave dividers, reveal animations, sticky nav - ale bez library bloat.

🎯 Działania

  • Design system: kolory, typografia, spacing, radius
  • Komponent library: nav, hero, cards, FAQ, footer
  • Homepage + oferta + zapytanie (core funnel)
  • Deep offer pages (kanapki, catering, programy)
  • City landing pages × N miast
  • Blog index + article template
  • Shared style.css extraction

📦 Deliverables

  • 25+ responsive stron HTML
  • Shared style.css + mn.js
  • SVG icon system
  • WebP optimized images
  • Mobile drawer menu
  • Exit-intent popup

🔧 Narzędzia

04
✍️
Content & SEO
Treść, meta tagi, schema, internal linking, AEO
▼
Content nie jest "dodawany na końcu" - jest częścią budowy. Każda strona dostaje unikalne meta title + description, Schema JSON-LD, OG image, internal links. Blog to SEO engine, nie afterthought. AEO (AI Engine Optimization) to nowy standard obok klasycznego SEO.

🎯 Działania

  • Unikalne meta titles + descriptions per strona
  • Schema JSON-LD (6+ typów)
  • OG images + Twitter cards
  • Blog keyword research + content plan
  • Migracja wartościowych artykułów
  • Internal linking strategy
  • FAQ sekcje z FAQPage schema

📦 Deliverables

  • SEO spreadsheet (URL, title, desc, schema)
  • 10+ artykułów blogowych
  • Content plan na 20 kolejnych
  • OG image 1200×630
  • Internal linking map

🔧 Narzędzia

05
⚡
Performance & QA
PageSpeed, mobile audit, a11y, bugfix cycles
▼
Każda iteracja kończy się cyklem QA. Nie ma "deploy and pray" - jest screenshot every page at 375px, Lighthouse per strona, checklist a11y. Bugfixy idą w batch commitach, nie w hotfixach o 3 w nocy.

🎯 Działania

  • Lighthouse audit (mobile + desktop)
  • Mobile responsive check (375px, 768px, 1024px)
  • WCAG 2.1 AA - skip-link, focus-visible, ARIA
  • Image optimization (WebP, lazy load, fetchpriority)
  • Kill bloat: unused CSS, JS libraries, duplicate assets
  • Cross-browser testing

📦 Deliverables

  • PageSpeed raport (95+ mobile target)
  • Mobile screenshot deck
  • Bug tracker z priorytetami
  • Accessibility audit report
  • Asset size inventory

🔧 Narzędzia

Lighthouse PageSpeed Insights Chrome DevTools Pillow/WebP axe DevTools
06
🚀
Launch & Deploy
Git → GitHub → Vercel auto-deploy, DNS, weryfikacja
▼
Deploy pipeline: git push → GitHub → Vercel auto-deploy w <60 sekund. Zero downtime, instant rollback. DNS migration to oddzielny krok - nie zmieniaj nameserverów w piątek o 17:00. GTM/GA4 tracking odpala się dopiero po weryfikacji live.

🎯 Działania

  • Git repo setup + .gitignore
  • Vercel project link (GitHub integration)
  • Konfiguracja custom domain + SSL
  • 301 redirect map w vercel.json
  • GTM container + GA4 property
  • Event tracking (form_submit, CTA clicks)
  • Google Search Console submit sitemap

📦 Deliverables

  • Live site na custom domain
  • Vercel dashboard z deploys
  • GTM container z event tags
  • GA4 realtime verification
  • Search Console indexed pages

🔧 Narzędzia

Git GitHub Vercel GTM GA4 Search Console
07
🔄
Iteracja & Growth
CRO, formularze, kalkulatory, blog engine, A/B testy
▼
Strona po launchu to v1.0, nie final. Iteracja oparta na danych: co konwertuje, co nie, gdzie ludzie odpadają. Dodajesz interaktywne elementy (kalkulator, quote builder, formularze), rozbudowujesz blog, testujesz CTA copy. Każda zmiana = commit + deploy + verify.

🎯 Działania

  • Formularz kontaktowy z progressem
  • Kalkulator kosztów / quote builder
  • Exit-intent popup z lead magnet
  • Blog content machine (nowe artykuły)
  • Case studies + social proof
  • CRO: testy CTA, copy, layout
  • Cykliczny re-audyt (co 2-4 tygodnie)

📦 Deliverables

  • Interaktywne komponenty
  • Blog z nowym contentem co tydzień
  • Monthly performance report
  • Conversion funnel analysis
  • Iteracyjny backlog (nowe taski)
